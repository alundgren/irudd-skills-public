UX before and after

Every pair in references/examples/, rendered so there is something to look at. Each one is a screen that went wrong in a plausible way, next to the fix.

This page is for a person. An agent should load the single markdown file for the pair it needs, not this. The words in each file are the guidance, these renders are just the pictures.
